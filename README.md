# DRC — iOS

تطبيق آيفون لمنصّة [Dreamer Community](https://dreamerc.org): واجهة iOS أصلية (شريط تبويبات، سحب للتحديث، اهتزاز اللمس، سفاري داخلي للروابط الخارجية) فوق الموقع نفسه.

- المشروع يتولّد من `project.yml` بأداة XcodeGen، والبناء كله على GitHub Actions (لا يحتاج ماك).
- كل دفعة على `main` تبني نسخة غير موقّعة وترفعها إلى إصدار `latest`، ومعها لقطات من محاكي آيفون.
- التثبيت: SideStore يوقّع النسخة على الجوال بحساب Apple ويجدّدها تلقائياً.
